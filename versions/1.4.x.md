# 1.4.x 버전 이력

## 1.4.0

1. 탭 가로 overflow 가장자리 fog 효과

2. 모바일 상태 표시줄 제작자·북마크 정보 표시 개선

3. 좌우 패널 간 탭 이동 단축키 및 에디터 포커스 수정

4. 데스크톱 단축키 안내 패널 추가

5. Cmd+N·Alt+N 및 Option+W 단축키 제거

<br>

## 1.4.1

1. 모바일 탭 전환 시 가상 키보드 재오픈 방지

2. 하단 상태 표시줄 구분자·정렬 및 모바일 정보 표시 개선

3. PRD와 요구사항별 E2E 구조 정리 및 동기화

4. PRD 문서를 `tests/PRD.md`로 이동

<br>

## 1.4.2

1. 모바일 브라우저 뒤로가기로 열린 북마크·그룹 패널을 X 버튼과 같은 방식으로 닫고 메모 화면으로 복귀

2. 선택 줄 강조 배경을 민트 신호색으로 변경해 가독성 개선

3. 버전 이력을 `versions/` 아래 버전군별 파일로 분리해 관리

<br>

## 1.4.3

1. 모바일 탭과 조작 버튼의 브라우저 기본 파란 터치 강조 효과 제거

2. 분할 비율을 재접속 시 중앙으로 초기화하고, 오른쪽 패널에 새 탭 추가 시 중앙으로 재조정

3. Shift+클릭 라인 범위 선택·연속 선택 블록 해제 및 SHORTCUT 안내 지원

<br>

## 1.4.4

1. 탭 색상을 그레이·블루·그린으로 순환하고 탭 배경, 핀, 선택된 줄 색상을 동기화

2. 탭 색상별 아이콘 glow를 적용하고, 편집 중에도 아이콘 크기 유지

3. 기존 긴급 표시 데이터를 탭 색상 상태로 변환해 복원

<br>

## 1.4.5

1. 탭 블루 팔레트와 색상별 아이콘 glow 개선

2. 모바일 편집기 레이아웃과 폰트 크기를 PC와 동일하게 통일

3. 브라우저 뒤로가기로 SHORTCUT 패널 닫기 지원

<br>

## 1.4.6

1. 북마크·그룹 검색창 위치와 여백을 통일하고 그룹 생성 입력란 위로 배치

2. 에디터 상단 여백과 줄 번호·본문 정렬을 조정하고 첫 줄 선택 배경을 상단 여백까지 연결

3. 첫 줄 선택 배경의 중복 합성을 방지해 다른 줄과 동일한 색상으로 표시

<br>

## 1.4.7

1. 에디터 폰트 크기를 19px, 줄 높이를 33px로 확대하고 줄 번호·선택 강조 영역 정렬 유지 및 모든 텍스트 입력 커서를 그레이로 통일

2. 하단 상태 표시줄 폰트를 2px 확대하고 상하 패딩을 각각 1px 추가해 전체 높이를 36px로 조정하며 모바일 그룹 이름의 말줄임 최대 너비를 1.5배 확대

3. 탭 블루 색상과 기존 저장 데이터를 레드로 변경하고 기본 색상을 그린, 순환 순서를 그린·그레이·레드로 조정하며 색상 아이콘과 버튼 영역의 가로·세로 크기를 각각 1px 확대

4. 모바일 탭 고정·북마크 메뉴를 탭 제목 더블탭으로만 표시하고 PC 우클릭 동작 유지

5. PRD의 복합 요구사항을 분리하고 요구사항별 E2E 번호를 동기화하며 공유 상수를 `__constant__/`로 정리
