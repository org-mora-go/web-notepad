# 1.5.x 버전 이력

{1.5.9 이력 작성 시점에 요약본 작성}

<br>

## 1.5.0

1. feature와 widget 모듈의 구현 및 export 구조를 통일하고 `PaneDivider`를 page 모듈로 이동

2. page·widget·feature의 메인 SCSS를 각 모듈의 `index.scss`로 정리하고 최상위 클래스를 모듈명에 맞춤

3. Sass 변수 파일명을 `variable.scss`로 변경하고 불필요한 `style/index.ts` barrel 제거

4. 드래그 드롭 종료 시 hover 상태가 남지 않도록 초기화 동작 개선

5. `shortcut-help` 위젯을 `shortcut`으로 이름 변경하고 패널 제목을 `Shortcut`으로 간결하게 표시

<br>

## 1.5.1

1. PRD와 E2E 요구사항을 현재 기능에 맞게 재구성하고 제거된 줄 수 표시 요구사항을 정리

2. 북마크 항목을 서브 컴포넌트로 분리

3. 상태 표시줄 저장 상태 아이콘을 제거하고 SHORTCUT, BOOKMARK, 그룹 명령의 순서와 구분자 간격 조정

4. Enter 입력 후 커서가 편집기 높이를 넘으면 커서 위치로 편집기와 줄 번호 영역을 스크롤

5. 상태 표시줄의 상하 및 좌우 패딩을 각각 2px 확대하고 전체 높이를 40px로 조정

<br>

## 1.5.2

1. 검색·그룹 입력에서 Cmd+A 전체 선택을 보정하고 한글 입력에서도 즉시 선택되도록 개선하며 검색창 지우기 아이콘을 옅은 색상으로 조정

2. 그룹 목록 간격을 14px로 확대하고 그룹 생성 후 패널을 열린 상태로 유지

3. `Ungrouped`를 그룹 목록 맨 위에 고정하고 옅은 회색으로 표시

4. 줄 번호를 마우스로 선택할 때 포커스 테두리가 생기지 않도록 개선

5. Shortcut 안내 콘텐츠 글자 크기를 2px 확대하고 macOS 단축키 표기의 `Alt`를 `Option`으로 변경

<br>

## 1.5.3

1. Shortcut·북마크·그룹 패널 헤더의 상하 패딩을 확대

2. 북마크·그룹 검색 입력과 그룹 생성·이름 수정 입력의 높이를 각각 6px 확대

<br>

## 1.5.4

1. 상태 표시줄 하단 패딩을 추가

2. 검색창 상단 여백을 줄이고 상태 표시줄 명령 사이의 간격을 확대

3. PC와 모바일 탭의 최소 너비를 각각 2px 확대

4. PRD와 E2E 요구사항을 기능·스타일 및 세부 동작별로 재구성

<br>

## 1.5.5

1. 편집 영역이 좁아져 자동 줄바꿈이 늘어나면 LINE 번호와 선택 강조 영역도 표시 줄 수에 맞춰 확장

2. 탭 메뉴의 Pin·Bookmark 및 해제 문구 글자 크기를 12px에서 14px로 확대

3. 내용이 있는 탭을 닫을 때 영어 삭제 확인 팝업을 표시하고 Delete 또는 Alt/Option+Backspace로 삭제 확인, Escape로 취소 지원

4. Escape로 우측 그룹·북마크·단축키 패널을 닫고 하단 버튼의 포커스 테두리 잔상을 제거하며 삭제 팝업 취소와 키보드 탐색 포커스 표시 유지

5. 탭 메뉴에 Move Group을 추가해 탭과 연결 북마크를 다른 그룹으로 이동하고 내용·색상·고정·줄 선택 및 분할 패널 상태를 보존·정리
